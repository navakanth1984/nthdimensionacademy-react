Technical & Agentic Upgrades Staged

Raw HTML Prerender Resolved • Essential

Problem: Search spiders and non-JS AI bots parsed only 50 characters of empty markup (<div id="root"></div>).

Solution: Injected 1,754 characters of semantic HTML inside #root including structured <h1>, <h2>, course catalog, instructor credentials, and navigation links. React 19 cleanly hydrates and replaces it on load.

Robots Directives Resolved • Technical

Problem: /robots.txt was missing (returned 404), causing AI bots to fall back to restrictive crawl assumptions.

Solution: Created public/robots.txt explicitly granting crawl permissions to Googlebot, Bingbot, GPTBot, ClaudeBot, PerplexityBot, Applebot, meta-externalagent, and pointing to the XML sitemap.

XML Sitemap Resolved • Discoverability

Problem: No sitemap.xml existed to declare indexable URLs and priority weights.

Solution: Published public/sitemap.xml indexing the homepage, all 5 certification learning atlases (DP-600, DP-700, DP-750, DP-800, AI-103), and trust anchors with lastmod dates.

LLMs.txt & Agent Guidance Resolved • GEO / Agentic

Problem: Frontier AI agents had no machine-readable guidance or "When to use" decision rules.

Solution: Built public/llms.txt and public/llms-full.txt defining exact routing criteria, prerequisites, learning outcomes, and direct links for AI chat assistants.

Markdown Negotiation & 404s Resolved • Edge Engine

Problem: HTTP requests with Accept: text/markdown returned raw HTML without Vary: Accept.

Solution: Implemented Vercel Edge Middleware in middleware.js returning clean markdown summaries with Content-Type: text/markdown; charset=utf-8 and agent-friendly 404 error bodies.

JSON-LD Entity Graph Resolved • Schema Authority

Problem: Homepage lacked structured entity markup for organizations and courses.

Solution: Implemented Schema.org @graph combining EducationalOrganization, Person (Navakanth Reddy Dumpa, MCT), and ItemList containing 5 individual Course entities.

Trust Anchor Pages Resolved • Quality Signals

Problem: Search engines require verified trust anchors (About, Contact, Privacy, Terms) with >500 characters of content.

Solution: Built dedicated static pages at /about/, /contact/, /privacy/, and /terms/ with compliant legal copy and transparent organization disclosure.

Footer Navigation Resolved • Crawl Depth

Problem: Footer had limited 2-column links with missing internal routes.

Solution: Upgraded Footer.jsx to a 4-column responsive grid linking all 5 Learning Atlases, all Trust & Governance pages, contact channels, and MCT badge.
